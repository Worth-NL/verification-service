# Email and phone Verification service for NotifyNL

You can use this service to contact NotifyNL to send verification requests to. If you have an account in NotifyNL you can simply create email and sms teplates using the ((code)) stub in your template and use these templateId's through the API.

API docs can be found here.

Alternatively, you can run this code yourself and still connect to NotifyNL using the environment variables for templateing and API keys if so desired.
